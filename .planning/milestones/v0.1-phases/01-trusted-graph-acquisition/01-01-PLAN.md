The tracer establishes these stable contracts for later expansion plans:
- `read_mailbox.AcquisitionConfig`: immutable validated policy for mailbox, folder, allowlists, cutoff, transfer limits, fingerprint length, and output directory.
- `read_mailbox.run_acquisition(config, credentials, graph_factory, session_factory, event_sink) -> DownloadResult`: one ordered orchestration seam with injectable external boundaries.
- `vicmap_acquire.graph.MessageMetadata`: project-owned `graph_message_id`, aware UTC `received_datetime_utc`, and normalized sender/subject source strings; no O365 object leaves the adapter.
- `vicmap_acquire.candidates.Candidate`: validated order ID, received instant, complete ordering ID, sender, and artifact URL; display truncation is excluded from this type.
- `vicmap_acquire.download.DownloadResult`: finalized path, exact integer byte count, and full lowercase SHA-256 digest.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| environment/TOML → CLI | Secret environment values and non-secret policy enter process control flow. |
| Microsoft Graph → domain policy | O365 metadata and selective MIME are untrusted external data. |
| message URL → artifact HTTPS | Email-controlled URL data could redirect or exfiltrate Graph authority. |
| HTTPS stream → filesystem | Remote bytes must remain bounded and incomplete output must not appear final. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Information disclosure | `read_mailbox.py`, `graph.py` | high | mitigate | MemoryTokenBackend, import guard, third-party log suppression seam, closed events, and seeded disclosure assertions in Task 1. |
| T-01-02 | Spoofing | `candidates.py` | high | mitigate | Independent exact sender/order/subject/filename checks and full validation before deterministic selection in Task 1. |
| T-01-03 | Information disclosure | `download.py` | high | mitigate | Clean session with no Graph state or ambient auth plus validate-before-send for initial and redirected targets in Task 1. |
| T-01-04 | Denial of service | `download.py` | high | mitigate | Configured connect/read timeout tuple, bounded redirect loop, and exact observed-byte ceiling in Task 1. |
| T-01-05 | Tampering | artifact finalization | medium | mitigate | Private temporary file, incremental SHA-256, no-overwrite publication, and cleanup assertions in Task 1. |
| T-01-06 | Repudiation | operator evidence | low | accept | Redacted fingerprints and full artifact digest provide sufficient one-run correlation without introducing durable audit state, which is outside this phase. |
