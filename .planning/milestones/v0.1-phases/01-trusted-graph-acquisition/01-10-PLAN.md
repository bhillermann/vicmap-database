## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Microsoft Graph → adapter | Provider responses and SDK behaviour are outside project control and must not widen what the adapter fetches or exposes |
| Adapter → mailbox state | The mailbox is a shared production resource; this phase must only read it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-10-01 | Information disclosure | SDK-issued ordinary message representation fetch | high | mitigate | Single connection-level GET to the MIME value endpoint so a non-qualifying default body is never retrieved (Task 1) |
| T-01-10-02 | Tampering | mailbox mutation during scanning | high | mitigate | Recorded-request method and path assertions across a complete scan, plus a public-surface name check (Task 2, PROHIB-01 evidence) |
| T-01-10-03 | Information disclosure | provider response text reaching operator output | high | mitigate | Closed `GraphScanFailed` translation with seeded-marker exclusion regressions (Task 1) |
| T-01-10-04 | Spoofing | a manipulated message ID producing an unintended request URL | medium | mitigate | Percent-encode the complete opaque ID with an empty safe set and assert one well-formed request (Task 1) |
| T-01-10-05 | Elevation of privilege | contacting a resource outside the configured mailbox | high | mitigate | Build the URL from the confirmed folder's own resource rather than any caller-supplied address, and reject any folder other than `Inbox` (Task 1, Task 2) |
| T-01-10-06 | Denial of service | unbounded paging on a hostile page sequence | low | accept | The `receivedDateTime` cutoff bounds the window per D-07; a secondary count cap is explicitly excluded by D-08 |
| T-01-10-SC | Tampering | package installs | high | mitigate | No npm/pip/cargo install occurs in this plan; the pinned O365 2.1.0 build already present in the Nix devShell is used unchanged, so no package-legitimacy checkpoint is required |
