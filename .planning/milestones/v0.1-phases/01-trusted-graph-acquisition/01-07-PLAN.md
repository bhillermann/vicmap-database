Give `_AnchorCollector` an integer `non_rendered_depth` initialised to `0`. Gate both collectors on the counter: `handle_starttag` must skip href collection when `non_rendered_depth` is greater than `0`, and `handle_data` must skip `extract_text_urls` entirely when `non_rendered_depth` is greater than `0`.

Add `handle_comment` as a no-op override so comment text is never routed into `visible_urls`. Add `handle_decl`, `handle_pi`, and `unknown_decl` as no-op overrides for the same reason.
