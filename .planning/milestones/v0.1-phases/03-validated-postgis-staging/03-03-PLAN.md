<objective>
Fix the closed failure and success vocabulary the whole database boundary will speak, and give
Phase 3 a digest-verified way to read Phase 2's frozen manifest back off disk.

Purpose: `evidence.py`'s `SafeFailure.__init__` does a bare `_FAILURE_POLICY[reason]` lookup
with no default, so a reason code added without its policy entry is a `KeyError` at first use —
the failure path failing. Fixing the whole vocabulary once, before any staging code exists,
means 03-04 through 03-06 raise typed failures instead of inventing output. And Phase 2 wrote
`manifest.json` but never wrote a reader; Phase 3 cannot start without one.
Output: Four new stages, thirteen new reason codes with hints, four new event constructors, and
`read_manifest`.

No connection is opened and no driver is imported by either file this plan touches.
</objective>

  <action>Phase 2 wrote `manifest.json` and `manifest.json.sha256` but never wrote a reader. Phase 3's input is that pair, so add the reader to `vicmap_acquire/manifest.py` — the module that owns the contract — rather than re-deriving the payload shape in `staging.py`.

Add two closed failures beside the existing `ManifestWriteFailed`, following the same `code`-only idiom: `ManifestUnreadable` with `code = "manifest_unreadable"` and `ManifestDigestMismatch` with `code = "manifest_digest_mismatch"`. Neither carries file text, JSON text, or a path in its message.

Add `read_manifest(run_directory: Path) -> ImportManifest`. It is the exact inverse of `write_manifest` and must agree with it byte for byte:

1. Read `run_directory / "manifest.json"` as UTF-8 and `run_directory / "manifest.json.sha256"` as UTF-8. Any `OSError` or `UnicodeError` is `ManifestUnreadable`.
2. Recompute the digest over the canonical bytes exactly as `write_manifest` did: strip exactly one trailing newline from the file text, encode UTF-8, `hashlib.sha256(...).hexdigest()`. Compare against the sidecar's content with its own trailing newline stripped. A mismatch — or a sidecar that is not 64 lowercase hex characters — is `ManifestDigestMismatch`. Verify the digest **before** parsing the JSON, so a tampered file is rejected on identity rather than on shape.
3. Parse the JSON and rebuild the frozen objects: `FieldProfile` from each `fields` entry, `LayerProfile` from each `layers` entry (turning the `extent` list back into a 4-tuple, or `None`), `ManifestLayer(profile=..., target_table=...)`, `CompanionFile` from each `companions` entry, and `ImportManifest` from the `provenance` object plus the two tuples. Every collection becomes a `tuple`, never a list, so the returned object is as frozen as the one `build_manifest` produced.
4. Reject anything whose shape does not match: a `schema_version` that is not exactly `MANIFEST_SCHEMA_VERSION`, a missing or misspelled key at any level, a value of the wrong type, or a `layers`/`companions` value that is not a list. All of these are `ManifestUnreadable`. Follow `discovery.read_field_schema`'s total-collapse pattern — an inner `except (KeyError, TypeError, ValueError, json.JSONDecodeError)` re-raising the closed failure `from None`, wrapped by `except ManifestFailure: raise` so a specific failure is never masked by the catch-all.
5. Preserve element order exactly: `layers` and `companions` come back in the order the file lists them, because D-42 loads layers in that order and `write_manifest` never sorted those arrays (only object keys).

Do not import `psycopg`, `psycopg2`, `sqlalchemy`, `asyncpg`, or `pg8000` — `tests/test_manifest.py`'s existing forbidden-import policy test covers the Phase 2 path and this reader must not change that answer.
