<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| loader connection → PostgreSQL (vicmap / vicmap_staging / vicmap_audit) | privileged DDL, the authorized DROP, and reader GRANT cross here |
| promoting transaction → any other session | MVCC boundary: no change is visible until commit |
| composed SQL identifiers → server | only sql.Identifier/sql.Literal-composed text crosses |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering / Information Disclosure | partial/torn publication | critical | mitigate | every layer's move is in one transaction with a single commit; MVCC guarantees no session sees a partial order; a failure rolls the whole set back (PUB-02) |
| T-04-04 | Tampering | prior-generation DROP (D-71) | high | mitigate | exactly one schema-qualified single-target `DROP TABLE IF EXISTS vicmap.{table}`, no wildcard and no cascade modifier, never a loop over unlisted tables; asserted by positive render check and the rollback-preserves-prior live test |
| T-04-06 | Tampering | publication gate | critical | mitigate | promotion refuses unless every manifest layer has a PASS audit row for (run_ts, manifest_digest); a missing row raises PublicationValidationMissing before any DDL |
| T-04-02 | Elevation of Privilege | in-transaction reader GRANT | high | mitigate | only `GRANT SELECT` to reader_user, issued in the same transaction as the rename so no exists-but-unselectable window (D-73); reader gets no write |
| T-04-05 | Tampering | composed DDL identifiers | high | mitigate | all identifiers via sql.Identifier, values via sql.Literal/binds; current object names read from pg_constraint/pg_indexes, never string-derived (Pattern 1) |
| T-04-10 | Tampering | PostgreSQL 18 named NOT NULL rename | medium | mitigate | rename set discovered from the catalog (contype in p,n) at promotion time, correct on 17 and 18 with no version branch (Pitfall 2); SELECT version() is the first live action |
| T-04-SC | Tampering | package installs | low | accept | Phase 4 installs no new package (04-RESEARCH.md Package Legitimacy Audit: not applicable) |
</threat_model>
