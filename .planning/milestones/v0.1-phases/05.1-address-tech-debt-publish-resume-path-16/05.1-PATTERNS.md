### New connect helper for audit/detection reads (D-90) — `vicmap_acquire/publish.py`

**Analog:** `vicmap_acquire/publish.py::_connect` (lines 203-244) and `_connect_as_reader` (lines 499-537)

**Core pattern to copy — `_connect`'s shape, with a NEW failure mapping (never `PromotionFailed`)**:
```python
def _connect(policy: PublishPolicy, password: str) -> "psycopg.Connection":
    try:
        connection = psycopg.connect(
            host=policy.host, port=policy.port, dbname=policy.dbname,
            user=policy.user, password=password,
            connect_timeout=policy.connect_timeout_seconds,
        )
    except Exception:
        raise PromotionFailed() from None   # <-- REPLACE with a new AuditReadFailed for the new helper

    try:
        with connection.cursor() as cursor:
            cursor.execute(sql.SQL("SET statement_timeout = {}").format(
                sql.Literal(policy.statement_timeout_seconds * 1000)))
            cursor.execute(sql.SQL("SET lock_timeout = {}").format(
                sql.Literal(policy.lock_timeout_seconds * 1000)))
        connection.commit()
    except Exception:
        connection.close()
        raise PromotionFailed() from None   # <-- REPLACE with AuditReadFailed here too
    return connection
```
Copy this shape verbatim for the new detection/audit-read connect helper (Pattern 2 in RESEARCH.md), renaming the two `except Exception: raise PromotionFailed()` sites to raise a new closed exception whose `.code == "db_audit_read_failed"`. `_connect_as_reader` (lines 499-537) is the second precedent for "a distinct connect helper with its own closed failure class" already existing in this exact file — proof this is the established pattern, not a new one.

**Existing closed-exception idiom to mirror** (`vicmap_acquire/publish.py` lines 145-201):
```python
class PublishFailure(RuntimeError):

    def __init__(self) -> None:

class ReaderRoleUnavailable(PublishFailure):

```
New exception classes (`AuditReadFailed` with `.code = "db_audit_read_failed"`, `PublicationSummaryFailed` with `.code = "pub_summary_failed"`) should subclass `PublishFailure` exactly like `ReaderRoleUnavailable` does, overriding only `code`.

**Privilege-vs-generic split to reuse** (`assert_all_layers_validated`, lines 271-288, and `read_layer_validations`, lines 699-718 — both already do exactly the split D-90 requires):
```python

            rows = cursor.fetchall()

        raise AuditPrivilegeDenied() from None
```

This is the exact block to copy for both the new classification reads and for fixing `read_layer_validations` (Pitfall 2: `read_layer_validations` at line 699 currently calls `_connect(policy, password)` — the promotion-mapping helper — and must be switched to call the new audit-read connect helper instead, changing only the `except Exception:` target from `PromotionFailed` to the new `AuditReadFailed`).

```python
def assert_all_layers_validated(policy, password, *, run_timestamp, manifest_digest, target_tables) -> None:
    required = set(target_tables)
    connection = _connect(policy, password)
    try:
        with connection.cursor() as cursor:
            cursor.execute(
                sql.SQL("SELECT target_table, verdict FROM {table} "
                        "WHERE run_ts = %s AND manifest_digest = %s")
                    .format(table=sql.Identifier(AUDIT_SCHEMA, AUDIT_TABLE)),
                (run_timestamp, manifest_digest),

        raise AuditPrivilegeDenied() from None
    except PublishFailure:
        raise
    except Exception:
        raise PromotionFailed() from None

    if not required.issubset(passed):
        raise PublicationValidationMissing()
```
