<objective>
Make a resumed run visible and safely repeatable, and give the summary step its own failure
boundary.

Purpose: D-84 requires a resumed run to be distinguishable in both outputs; D-85 makes a re-run after
a fully successful run an ordinary resume, which turns `write_summary` into a real overwrite path that
must be atomic; D-91 gives summary assembly and writing their own `publication_summary` stage instead
of the current fall-through to `internal_failure`. Task 1 wires the visible resume end to end (event,
summary fields, live second and third runs). Task 2 makes the overwrite atomic and closes the summary
boundary, including the real-function proof that a plain re-run then completes the summary.

Output: `promotion`/`published_at` summary fields, `publication_resumed` emission, atomic
`write_summary`, and `PublicationSummaryFailed` raised by all three summary functions.
</objective>
