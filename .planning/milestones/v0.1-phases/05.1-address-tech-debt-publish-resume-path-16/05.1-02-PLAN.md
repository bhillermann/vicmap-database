<objective>
Make every published state that is not provably this run's own fail closed, with a named reason and
no DDL.

Purpose: Plan 05.1-01's tracer resumes only the clean case (every layer resumable) and maps
everything else to `pub_generation_ambiguous`. ROADMAP SC4 and D-86/D-87 need precise answers:
a generation this run published that was later replaced is `pub_generation_superseded`; a live table
with no marker for this run (including the pre-fix `vicmap.vmadd_address`, D-88) or an inconsistent
mix is `pub_generation_ambiguous`. Every one of those paths must leave production untouched. Task 1
proves the superseded slice end to end, live; Task 2 closes every remaining case with exhaustive
tables and a second live proof.

Output: the complete verdict precedence, resume-record consistency checks, and two live fail-closed
tests in `LivePublishOrderResumeTest`.

Planner decision recorded here: D-86 lists "Any C → superseded" and "Any D, or E → ambiguous",
which conflict for mixed orders. The precedence is: superseded only when every layer still carries
this run's publication row (so this run really did publish the whole order and part of it was
replaced since); any unproven, conflicted, or staged layer mixed into the set makes the audit trail
itself inconsistent, and that is ambiguous. Both outcomes fail closed with no DDL; only the
remediation hint differs. The conflicted case (staging table present while this run's marker also
exists) is not enumerated by D-86 and is resolved fail-closed as ambiguous.
</objective>
