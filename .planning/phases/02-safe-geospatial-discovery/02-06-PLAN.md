## Trust Boundaries

| Boundary | Description |
|---|---|
| discovered profiles → `manifest.json` | Untrusted-origin metadata becomes the durable contract Phase 3 builds DDL from and Phase 4's summary cites. |
| pipeline internals → operator output | Full filesystem paths, real layer names, and driver text exist internally and must not reach stdout or logs. |
| failed run → run root | A failed run must leave no artifact that a later phase could mistake for a completed handoff. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-31 | Tampering | manifest publication | high | mitigate | Every GEO-05 hard stop is proven to leave no manifest and no sidecar anywhere under the run root, asserted by a recursive glob rather than a single expected path, so Phase 3 can never act on a partial delivery. |
| T-02-32 | Tampering | manifest immutability | high | mitigate | An existing `manifest.json` in a run directory is never overwritten, and its SHA-256 sidecar makes post-hoc modification detectable. |
