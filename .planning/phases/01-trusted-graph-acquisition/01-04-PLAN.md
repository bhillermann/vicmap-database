<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| email-controlled URL → outbound network | An attacker can choose initial URL components and redirect Location values. |
| process environment → Requests session | Ambient proxy/netrc state and Graph authorization must not cross into artifact requests. |
| remote response → local filesystem | Headers and body bytes can be dishonest, oversized, stalled, partial, or concurrent with another run. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-04-01 | Spoofing | URL/redirect authority | high | mitigate | Task 1 validates exact HTTPS host, authority, and port before the initial request and every manually followed hop. |
| T-01-04-02 | Information disclosure | artifact Requests session | high | mitigate | Task 1 constructs a clean session with no Graph state and disables proxy/netrc inheritance; tests inspect every outgoing request. |
| T-01-04-03 | Denial of service | redirect/stream loop | high | mitigate | Task 1 bounds redirects/timeouts and Task 2 enforces declared plus observed byte ceilings with streaming memory use. |
| T-01-04-04 | Tampering | response representation and checksum | medium | mitigate | Task 2 requires identity encoding, exact declared/observed agreement when declared, and hashes persisted bytes in the write loop. |
| T-01-04-05 | Tampering | artifact finalization | high | mitigate | Task 2 uses restrictive private temp state and atomic hard-link no-overwrite publication with failure/interruption/concurrency tests. |
| T-01-04-06 | Repudiation | remote target evidence | low | accept | The downloader returns only approved hostname/path fingerprint inputs to the renderer; durable remote audit state is outside this phase. |
