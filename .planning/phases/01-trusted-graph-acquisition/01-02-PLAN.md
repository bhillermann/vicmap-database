<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| credential environment → O365/MSAL | Long-lived app credentials become short-lived Graph authorization. |
| O365 provider objects → project metadata | Provider-controlled fields and exception text cross into application code. |
| tenant application permission → configured mailbox | App-only permission breadth can exceed the intended automation mailbox. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-02-01 | Information disclosure | Account/token backend | high | mitigate | Task 1 uses MemoryTokenBackend only, suppresses raw library HTTP logs, and adversarially tests captured output. |
| T-01-02-02 | Elevation of privilege | mailbox resource selection | high | mitigate | Task 1 addresses only the configured mailbox; Plan 05's controlled proof requires an operator-confirmed read-only tenant resource scope before phase completion. |
| T-01-02-03 | Information disclosure | metadata/MIME boundary | medium | mitigate | Task 2 selects four metadata fields, retrieves MIME only for qualified headers, and keeps O365 objects/errors inside the adapter. |
| T-01-02-04 | Denial of service | pagination | medium | mitigate | Task 2 constrains time with the server-side cutoff while streaming every opaque next page rather than buffering the mailbox. |
| T-01-02-05 | Tampering | mailbox state | low | accept | The adapter invokes read APIs only and PROHIB-01 remains explicitly flagged for independent verification because no phase SPEC descriptor exists. |
</threat_model>
