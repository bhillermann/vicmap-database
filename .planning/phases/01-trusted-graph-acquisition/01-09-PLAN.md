## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TOML and programmatic policy → runtime | Two entry points that must enforce one identical contract before credentials are read |
| Environment credentials → adapters | Credential presence checked without any value entering output |
| Runtime → operator evidence | The only channel where redacted identifiers leave the process |
| Runtime → repository working tree | Finalized artifacts and private partials must never become stageable content |
